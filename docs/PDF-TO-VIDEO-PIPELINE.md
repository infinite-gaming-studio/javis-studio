# PDF 绘本视频合成架构

## 系统概述

将 PDF 绘本（或分页结构化文本）自动合成为带多角色配音、字幕和转场特效的完整视频。支持用户自定义脚本、角色音色、情感参数及特效配置。

## 模块说明

### 1. 输入层

接收 PDF 绘本文件或用户提供的结构化文本，以及角色音色、特效等配置。

### 2. PDF 解析服务

将 PDF 按页面顺序拆分为独立图片，建立 Page ID 与图片的映射关系。

### 3. 页面内容绑定

将用户提供的分页脚本与页面图片绑定，提取每页的旁白和角色对白文本。

### 4. 脚本解析器

通过 LLM 或规则引擎解析剧本，输出结构化内容：

- **旁白**（Narration）
- **角色对话**（Dialogue）
- **说话人标注**（Speaker Tagging）
- **时间轴段落**（Timeline Segment）
- **字幕 JSON / SRT**

### 5. 语音角色映射

维护角色到 TTS Voice ID 的映射表，并根据情绪标签生成 TTS 参数（语速、音高、情感风格）。

### 6. TTS 调度层

- 并发队列管理
- 任务拆分与合并
- 失败重试与降级
- API 速率限制控制

### 7. TTS 服务池

连接多种 TTS 引擎（IndexTTS2 / OpenAI TTS / Edge TTS 等），每角色独立通道。

### 8. 音频合成层

多轨音频混音：旁白 + 多角色对白，按时间轴对齐，输出混合音频。

### 9. 字幕生成服务

根据音频时间戳生成字幕文件（SRT / ASS / JSON）。

### 10. 视频合成引擎

每页合成为视频片段：页面图片 + 混音音频 + 字幕叠层，支持自定义特效渲染。

### 11. 转场处理

在页面间添加转场效果：淡入淡出 / 滑动 / 缩放 / 擦除。

### 12. 视频拼接层

将所有页面片段拼接为完整视频，统一字幕样式，进行全局音量均衡。

## 数据流总结

```
Input PDF → Page Images → Script Binding → LLM Parsing → TTS → Audio Mix
→ Subtitle Gen → Video Render → Transitions → Stitch → Final MP4
```
